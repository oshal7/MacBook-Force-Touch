How it works

  1. Capture. Safari exposes trackpad force as webkitForce (1 = click, 2 = force click, 3 = max). The native app reads NSEvent.pressure and stage.
  2. Join stages. Both are mapped to one continuous 0–1 range: click covers 0–0.5 and force click covers 0.5–1, so the value doesn't drop back to zero at the force click.
  3. Quantize. Calibration, curve and deadzone, then 10 bands. Rising pressure changes level immediately; falling pressure has to clear the hysteresis margin first.
  4. Feedback. Each level change plays an NSHapticFeedbackManager pulse natively. Here it's a visual pulse, plus optional sound or vibration.

Browser support: live Force Touch input works in Safari on a Mac with a Force Touch trackpad. Pens and some touchscreens report pressure through Pointer Events. Everything else can use the simulated input.

Native macOS harness

The Swift package ForceTouchKit includes the quantizer, calibrator, haptics and an NSView tracker, plus a SwiftUI test app that plays real haptics at each level.

git clone https://github.com/oshal7/MacBook-Force-Touch.git
cd MacBook-Force-Touch
swift run ForceTouchHarness

Requires macOS 11+ and Xcode 15+. To use the library in your own app, add the package and drop in a PressureTrackerView:

let tracker = PressureTrackerView()
tracker.onReading = { reading in
    print(reading.level, reading.raw) // 0–10, 0.0–1.0
}
